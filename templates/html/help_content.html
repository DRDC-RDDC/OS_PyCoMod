Help

This is an interactive PyCoMod model simulation tool.

Instructions:

  1. Adjust model parameters in the Inputs tab
  2. Configure run settings (duration, time step, mode)
  3. Click Run Model to execute the simulation
  4. View results in the interactive plot

Run Modes:

  • Single: Run one deterministic simulation
  • Monte Carlo: Run multiple stochastic simulations and show aggregated results
